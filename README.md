# 🤖 Hire Pavel Makarov Bot (Telegram Bot)

Интерактивный Telegram-бот-визитка, созданный для демонстрации навыков разработки и автоматизации процессов. 
Проект представляет собой не просто статичную страницу с контактами, а полноценное приложение с меню и автоматизированным пайплайном доставки кода (CI/CD).

## 🚀 Текущий функционал
*   Интерактивное меню: Inline-клавиатура с основными разделами (Обо мне, Соцсети, Связаться, Заказать бота).
*   Обработка событий: Асинхронная обработка нажатий на кнопки с помощью aiogram 3.

## 🛠 Стек технологий
*   Язык: Python 3.10+
*   Фреймворк: aiogram 3.x (асинхронный)
*   Безопасность: python-dotenv (хранение токенов в переменных окружения)

## ⚙️ DevOps & Deployment (Инфраструктура)
Проект развернут на удаленном Linux-сервере (VPS) и настроен по стандартам production-разработки:
*   Процесс-менеджер: Настроен systemd (служба tgbot.service), который обеспечивает бесперебойную работу бота 24/7 и автозапуск при перезагрузке сервера.
*   CI/CD Pipeline: Настроен GitHub Actions (.github/workflows/deploy.yml). Любое изменение, отправленное в ветку main, автоматически деплоится на сервер (обновление кода через git pull и перезапуск службы systemctl restart).

## 📦 Установка и запуск (локально)
1. Клонировать репозиторий: git clone ...
2. Создать виртуальное окружение: python3 -m venv venv
3. Активировать его: source venv/bin/activate
4. Установить зависимости: pip install -r requirements.txt
5. Создать файл .env и добавить токен: bot_token=ВАШ_ТОКЕН
6. Запустить: python bot.py
